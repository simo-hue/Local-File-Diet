# Local File Diet website

Static GitHub Pages site for Local File Diet.

Deploy from GitHub repository settings:

1. Go to Settings > Pages.
2. Set Source to "Deploy from a branch".
3. Select branch `main`.
4. Select folder `/docs`.

Expected public URLs:

- Home: `https://simo-hue.github.io/Local-File-Diet/`
- Privacy Policy URL: `https://simo-hue.github.io/Local-File-Diet/privacy.html`
- Support URL: `https://simo-hue.github.io/Local-File-Diet/support.html`
- Terms URL: `https://simo-hue.github.io/Local-File-Diet/terms.html`
