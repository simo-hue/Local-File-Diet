Workflow

Built for quick file-size limits

Use it when a file is too large for email, upload forms, portals, or a fast share.

1

Import locally

Pick a file from Files, Photos, or the iOS share sheet. Originals are copied to a temporary local workspace.

2

Choose a target

Select a preset such as 25 MB, 10 MB, 5 MB, or enter a custom size in MB or KB.

3

Compress on-device

The app uses native iOS frameworks and keeps the work on the phone. No cloud compression service is used.

4

Share or save

Export the smaller file, save compressed media, or start another import from the result screen.

Privacy by design

No uploads. No account. No tracking.

Local File Diet is designed as a local-first utility. It does not require sign-in, does not include advertising SDKs, and does not collect file contents, file names, paths, analytics, or tracking identifiers.
